MyBatis 3 User Guide & Visual Documentation Suite

Welcome to the unofficial visual documentation and engineering suite for MyBatis 3 (v3.6.0)—the premier SQL-first persistence framework for Java—built with PNI501 and Drawlib.

Unlike monolithic Object-Relational Mappers (ORMs) that hide SQL behind opaque object-graph query languages, MyBatis couples Java methods directly to hand-crafted SQL statements via XML or Java annotations, while eliminating nearly 100% of raw JDBC PreparedStatement binding and ResultSet extraction boilerplate.

60-Second Quickstart

1. Add Maven Dependency

<dependency>
  <groupId>org.mybatis</groupId>
  <artifactId>mybatis</artifactId>
  <version>3.6.0</version>
</dependency>

2. Define a Java Record & Mapper Interface

MyBatis 3 natively maps SQL columns directly into immutable Java record canonical constructors:

package com.example.blog;

import java.time.LocalDateTime;
import java.util.List;
import org.apache.ibatis.annotations.Insert;
import org.apache.ibatis.annotations.Options;
import org.apache.ibatis.annotations.Param;
import org.apache.ibatis.annotations.Select;

public record Author(Long id, String username, String email, LocalDateTime createdAt) {}

public interface AuthorMapper {

  @Select("""
      SELECT id, username, email, created_at AS createdAt
      FROM authors
      WHERE id = #{id}
      """)
  Author findById(@Param("id") long id);

  @Select("""
      SELECT id, username, email, created_at AS createdAt
      FROM authors
      WHERE username LIKE #{pattern}
      ORDER BY id ASC
      """)
  List<Author> searchByUsername(@Param("pattern") String pattern);
}

3. Bootstrap SqlSessionFactory and Execute Queries

Build SqlSessionFactory once at application startup, then open short-lived SqlSession instances inside try-with-resources blocks per request:

import javax.sql.DataSource;
import org.apache.ibatis.mapping.Environment;
import org.apache.ibatis.session.Configuration;
import org.apache.ibatis.session.SqlSession;
import org.apache.ibatis.session.SqlSessionFactory;
import org.apache.ibatis.session.SqlSessionFactoryBuilder;
import org.apache.ibatis.transaction.jdbc.JdbcTransactionFactory;

// 1. Application-scoped singleton initialization
DataSource dataSource = createHikariDataSource();
Environment environment = new Environment("prod", new JdbcTransactionFactory(), dataSource);

Configuration config = new Configuration(environment);
config.setMapUnderscoreToCamelCase(true); // Maps created_at -> createdAt automatically
config.addMapper(AuthorMapper.class);

SqlSessionFactory sessionFactory = new SqlSessionFactoryBuilder().build(config);

// 2. Per-request execution using try-with-resources
try (SqlSession session = sessionFactory.openSession()) {
  AuthorMapper mapper = session.getMapper(AuthorMapper.class);
  Author author = mapper.findById(42L);
  System.out.println("Loaded author: " + author);
}

Chapter Roadmap

  1. 1. Installation & SqlSession Lifecycle: Maven/Gradle setup, SqlSessionFactoryBuilder -> SqlSessionFactory -> SqlSession -> Mapper thread-safety rules, and try-with-resources.
  2. 2. XML Configuration (mybatis-config.xml): Ordering of <configuration> elements, essential <settings> (mapUnderscoreToCamelCase, localCacheScope, defaultFetchSize), <typeAliases>, and <environments>.
  3. 3. Mapper XML & SQL Statements: <select>, <insert>, <update>, <delete>, auto-generated keys (useGeneratedKeys="true" & <selectKey>), #{} PreparedStatement binding vs ${} string substitution, and reusable <sql> fragments.
  4. 4. ResultMaps, Records & Associations: <resultMap>, immutable Java record <constructor> mapping, 1:1 <association>, 1:N <collection>, and avoiding the N+1 query pitfall with JOIN result maps.
  5. 5. Dynamic SQL & OGNL Tags: <if>, <choose>/<when>/<otherwise>, <where>, <set>, <trim>, <foreach> batch & IN (...) clauses, and <bind>.
  6. 6. Java Annotations & SQL Builder: @Select, @Results, @Arg, @One/@Many, and dynamic providers (@SelectProvider + org.apache.ibatis.jdbc.SQL).
  7. 7. L1/L2 Caching, Transactions & Batching: L1 session cache (localCacheScope), L2 namespace <cache>, jdk.serialFilter security, ExecutorType.BATCH, and Cursor<T> streaming.
  8. 8. TypeHandlers, Plugins & Testing: Custom BaseTypeHandler<T>, @Intercepts plugins on Executor/StatementHandler, and integration testing with ScriptRunner.
